# 商品與規格狀態（2026-10-09）

| 代碼 | 規格狀態 | 前台顯示與購買 |
| --- | --- | --- |
| 0 | 下架 | 隱藏此規格，不可購買；有其他販售規格時保留商品 |
| 1 | 上架 | 可超過實體庫存購買，每次最多 10 箱 |
| 2 | 缺貨 | 可超過實體庫存購買，每次最多 5 箱，提示備貨時間較長 |
| 3 | 即將售完 | 最多可買 min(庫存＋待進貨－待出貨, 10) 箱 |
| 4 | 永久停產 | 隱藏、不可購買，不參與自動上架；只有 ADMIN 可解除 |
| 5 | 售完 | 顯示售完且不可購買；若沒有其他可售規格，商品總覽不顯示該商品 |
| 6 | 預備上架 | 不可購買；供活動開始或商品手動上架時啟用 |

## 自動連動

- 有效販售狀態為 1／2／3。有其中任一規格時商品自動上架，沒有時自動下架；永久停產商品不會被自動恢復。
- 預估供應量＝庫存＋待進貨×良品率，比較時保留小數。
- 上架規格：預估供應量＋允許超賣量 < 待出貨時轉缺貨，等於時維持上架。
- 缺貨規格：預估供應量 ≥ 待出貨＋採購溢額量時恢復上架，僅限所屬商品仍上架。商品手動下架及永久停產不會被排程恢復。
- 即將售完規格的庫存＋待進貨－待出貨 ≤ 0 時，自動轉為售完，阻止繼續購買。
- 商品手動下架會將其規格 1／2／3／6 改成 0，保留 4／5。
- 商品手動上架但沒有 1／2／3：有 6 時直接將 6 啟用；只有 0 時詢問是否上架規格；只有 4／5 或沒有規格時阻擋操作。
- 售完規格不會自動上架。任何手動離開售完狀態的操作都需確認；改為上架時提示「該商品規格原為售完商品，請確認是否有貨源」。API 必須帶 restockConfirmed=true。
- 預備上架只可於新增時設定或保持原狀，離開後不能再選回。

## 規格數量設定

- max_backorder_qty：允許超賣量，預設 10。影響上架轉缺貨的門檻；設為 0 時不增加超賣緩衝量，不改變單次購買上限。
- purchase_add_on_qty：採購溢額量，預設 20。作為缺貨恢復上架所需的額外供應緩衝量，不會自動建立採購單。
- 原有規格編輯與狀態切換保留資料庫中這兩個欄位的設定。

## 良品率

按同 SKU、目前商品供應商統計，依 purchaseorder.inbound_date（驗收日期）由新到舊排序，取最近90天內最多30筆採購明細。只納入已核准且已驗收（成功或失敗）的紀錄；到貨必須大於0、不良品數介於0與到貨數之間。排除未驗收、未到貨及不合法資料，驗收失敗的有效品質紀錄仍列入。

R30、R5 分別是最近最多30筆、最近最多5筆的數量加權良品率：總良品數／總到貨數。若 R30−R5 > 0.08（8個百分點），採用R5；否則採用R30×0.7＋R5×0.3。不足筆數取現有紀錄；無有效紀錄預設90%，實際0%仍使用0%。同時驗收以採購單編號、明細編號由大到小作次序。

待進貨沿用 SKU 的未入庫數量，不重新累加採購單數量以免與庫存重複計算。訂單庫存變動後即時判斷；採購／驗收後由既有30秒排程同步。未變更狀態的排程檢查不會清除首頁快取。

## 活動時間

沿用既有「規格活動」的開始時間與規格清單，不另增一組日期欄位。活動啟用、開始時間已到且尚未結束時，每 30 秒檢查一次，僅將該活動的狀態 6 規格改為 1。狀態 4／5 及永久停產商品不受影響。

設定：product.availability-scheduler.enabled（預設 true）、product.availability-scheduler.delay-ms（預設 30000）。

## 結帳、出貨、取消

- 結帳：待出貨增加購買數量，實體庫存不變；後端重新驗證狀態、價格與數量上限，合併同規格數量檢查。
- 出貨：庫存與待出貨同時減少出貨數量，庫存不足時阻止出貨。
- 未出貨取消／退款：只釋放待出貨，不增加實體庫存。
- 訂單與規格加鎖處理，重複出貨或取消不會重複扣減。
- orders.inventory_state：0＝舊訂單、1＝已預留、2＝已出貨、3＝已釋放。舊訂單因原程式已扣庫存，不套用新版庫存處理；請勿將舊訂單一律改成 1。
- 已出貨退款不自動當作退貨入庫，退貨庫存需另依實際收貨處理。

目前資料庫已增加 inventory_state。其他組員匯入舊資料庫時，可使用 db/migrations/20261009_order_inventory_state.sql 補欄位。

## 舊規格資料轉換

只有首次部署、確定舊資料的狀態 5 全部代表「預備上架」時，才執行一次：

```sql
UPDATE product_sku SET status = 6 WHERE status = 5;
```

2026-10-09 已檢查目前資料庫，舊狀態 5 為 0 筆。新版使用後不可重複執行，避免把售完誤改為預備上架。
