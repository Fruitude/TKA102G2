# 商品規格狀態與供應量

本次使用新編碼，不能直接套用於舊資料庫而不轉換資料。

| 狀態 | 意義 | 單次可購買上限 |
|---|---|---|
| 0 | 下架 | 0，前台不顯示 |
| 1 | 上架 | min(10, B) |
| 2 | 缺貨 | min(5, B)，保留備貨較久的提示 |
| 3 | 即將售完 | min(5, C)，仍監控採購、不允許超賣 |
| 4 | 售完 | 0；有其他可販售規格時顯示售完 |
| 5 | 預備上架 | 0；商品上架或活動開始時啟用，離開後不可重新選擇 |
| 6 | 即將停產 | min(10, floor(max(0, 庫存−待出貨)))；不監控採購 |
| 7 | 永久停產 | 0；僅 ADMIN 可解除，任何有管理權者可設定 |

商品本身維持 0 下架、1 上架、2 永久停產。

## 供應量及良率

A = 庫存 + 待進貨 × R − 待出貨。
B = floor(max(0, A + 允許超賣量))。
C = floor(max(0, A))。

R 使用同規格、目前供應商、驗收日期 inbound_date 最近90天的有效驗收資料；最近30筆與最近5筆分別以總良品量／總到貨量計算，組合為 R30 × 0.7 + R5 × 0.3。短期良率低於長期超過8個百分點時使用R5。不足30筆取現有資料，無有效紀錄用90%，真實0%保留0%。

## 自動轉換

- 1／2：B=0 時先轉4；否則1且A低於安全庫存轉2，2且A至少安全庫存＋採購溢額轉1。
- 3：C=0轉4；A至少安全庫存轉2，至少安全庫存＋採購溢額則直接轉1。
- 4：只在實際良品入庫或取消訂單釋放待出貨後，且C至少1時恢復。先以3的規則判斷，直接存最終3／2／1，不循環寫狀態。一般排程不會自行恢復4；取消訂單可觸發恢復判斷。
- 6：待進貨為0且庫存−待出貨不大於0時轉7。進貨為正但沒有現貨時仍留6且無法購買。
- 0／5／7不參與一般供應量自動轉換。

商品有1／2／3時可自動上架；有6時，已上架商品保持上架，系統下架且允許恢復的商品可重新上架，手動下架的商品不自動恢復。沒有1／2／3／6時自動下架。手動商品下架會將1／2／3／5改0，保留4／6／7。

product.auto_restock_enabled區分手動下架與自動售完下架。手動下架關閉恢復；自動下架保留恢復資格，實際入庫或取消訂單釋放待出貨後可以重新上架。永久停產商品不自動變動。

手動解除售完需要確認貨源；手動設1但供應量不足時會依規則轉2／4，狀態API會回傳提示。不能用手動狀態繞過購買數量驗證。

## 採購及訂單

採購提醒監控1／2／3／4及允許補貨的商品，A低於安全庫存時列入。
建議量 = ceil(max(0, 安全庫存＋固定採購溢額−A)／R)。R=0顯示人工確認。
此專案目前提供採購提醒與建議量，並未新增自動建立採購單的工作。

沿用遠端訂單流程：送單增加待出貨；出貨減少庫存及待出貨；取消未出貨單釋放待出貨。購買限額在資料庫UPDATE內再次檢查。遠端出貨使用GREATEST(...,0)，因此庫存不足時數字會截到0，這是保留的組員行為。

驗收鎖定採購單、商品、規格並重新讀取規格，增加實際良品庫存、扣除已結束明細的待進貨，再判斷狀態。驗收寫入欄位仍維持組員版本。良率查詢遇到inbound_status為2／3，或po_status為3時，採購數量全數視為不良品，良品為0，不依賴寫入的到貨／不良品數字。取消單沒有inbound_date時使用order_date。

## 合併與部署

1. 停止應用程式並備份資料庫，確認尚未使用新編碼。
2. 執行db/migrations/20261011_sku_status_v2.sql一次。它保存原狀態並用migration紀錄阻止重複轉碼。
3. 使用本次程式碼重新啟動。請勿同時執行舊版本程式。

舊3即將下架轉新6；舊4永久停產轉7；舊5售完轉4；舊6預備上架轉5。舊下架商品預設不允許自動補貨恢復，需管理者確認後上架。

舊OrderInventoryService及20261009_order_inventory_state.sql保留供合併比對，正式訂單流程不再呼叫它；不要將舊migration作為本次必要部署步驟。

首頁沒有商品資料快取；圖片HTTP快取保留30分鐘。沒有恢復之前取消的購物車30秒及結帳5秒輪詢。

預備上架啟用後立即經過供應量判斷，直接存入最終1／2／4；若沒有可販售規格，商品同步下架。前台管理開關與批次結果使用後端實際狀態，不盲目顯示請求的上架狀態。

規格6自動只維持6或售盡轉7，不能自動變成1。商品因系統下架且允許恢復時，6可帶動商品上架；手動商品下架保留6並關閉自動恢復，6不能讓商品反彈。ADMIN可以將6手動改回一般狀態；6轉7仍屬停產方向，具管理權者可設定。
